Lab 35 - Packet Tracer - Use Telnet and SSH

By An Le

In lab 35, we will establish a remote connection to a router using Telnet and SSH.

Part 1: Verify Connectivity

Step1: Verify IP address on a PC.

We can use ipconfig to see the IP address. In this case, we see IPv4 192.168.1.11 and 192.168.1.12.

Step 2: Verify connectivity to HQ.

We can use ping command to verify connection to HQ 64.100.1.1.

Part 2: Access a Remote Device

Step 1: Telnet to HQ.

We follow the instruction to use telnet command to connect to HQ. However, the connection refused as the router is configured to not allow Telnet access due to security.
