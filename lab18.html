Lab 18 - Packet Tracer - Configure Basic Wireless Security

By An Le

In lab 18, we will configure basic wireless security using WPA2 Personal.

Part 1: Verify connectivity.

First, select the laptop, choose Desktop tab then choose web browser and entered www.cisco.pka. The page should be displayed.

Part 2: Configure basic wireless security.

To configure wireless, we need to access router's default IP address (192.168.1.1) and input admin as the default username and password (In real world, each manufacturer might have different IP, username, and password).
Choose Wireless menu then Wireless security, change 2.4GHz network to WPA2 Personal with the password Network123. Save and close the browser.

Part 3: Update the wireless settings on Laptop.

We then need to update the laptop wireless setting to reconnect to the network. Go to PC Wireless in the Desktop tab, connect to Academy with Pre-shared Key Network123. Connect then close the window.

Part 4: Verify connectivity.

Access the browser again and visit www.cisco.pka. The page should be displayed identical to Part 1.
